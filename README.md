## 🎨 Portfolio Features

- **Warm Sand & Charcoal Glassmorphism Theme**: A premium visual system featuring modern gradients, soft shadows, blur filters, and dynamic micro-interactions.
- **Interactive Hero Showcase**: Contains a live-rendered mobile mockup displaying dynamic profiles and a simulated digital store environment, standing side-by-side with a portrait of me.
- **Coding Projects Section**: Features premium landscape (16:9) clickable cards showcasing my live web applications:
  - **Biraj's Portfolio** ([Live Site](https://birajbiswas-portfolio.vercel.app/))
  - **ProCuts (Devanshu Pal's Video Editor Portfolio)** ([Live Site](https://devanshupal-portolio.vercel.app/))
- **Design Projects Slider**: A seamless, infinite scrolling slide track exhibiting visual design projects (`design0` to `design9`) created using Photoshop and Illustrator.
- **Click-to-Enlarge Lightbox**: Click on any design image to trigger a beautiful full-screen modal backdrop with a zoom blur overlay and close buttons.
- **Contact & Inquiry Form**: Integrates safely with **Web3Forms** for automatic, secure, real-time message forwarding directly to my inbox.
